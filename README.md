# README – Praktikum Tkinter Sesi 11

## 1. Tujuan
Membuat aplikasi GUI menggunakan Python Tkinter dengan menerapkan Advanced Widgets dan Event Handling.

## 2. Nama Aplikasi
**Aplikasi Pendaftaran Kegiatan Mahasiswa**

## 3. Fitur Aplikasi
- Mengisi nama mahasiswa.
- Memilih program studi dan jenis kelamin.
- Memilih kegiatan mahasiswa.
- Mengisi alasan mengikuti kegiatan.
- Menampilkan hasil pendaftaran.
- Validasi data.
- Tombol Submit dan Reset.
- Menu About dan Keluar.

## 4. Teknologi
- Bahasa pemrograman: Python
- Library: Tkinter
- Editor: Visual Studio Code

## 5. Cara Menjalankan
1. Pastikan Python sudah terinstal.
2. Buka folder proyek.
3. Jalankan terminal.
4. Ketik perintah berikut:

```bash
python main.py
```

5. Aplikasi akan terbuka dan siap digunakan.

## 6. Penutup
Aplikasi ini dibuat untuk memenuhi tugas Praktikum Python Tkinter Sesi 11 dengan materi Advanced Widgets dan Event Handling.
